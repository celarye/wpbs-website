This guide builds `greeter`, a [Rust](https://www.rust-lang.org) plugin that
logs a greeting, repeats it every morning, and answers to `!hello` and `/hello`
on Discord.

Every page adds to the same code, so follow them in order. The guide assumes you
know Rust and have it installed through [rustup](https://rustup.rs).
